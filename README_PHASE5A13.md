# GameBox 3D Runner - Phase 5A.13

Temple Runner Polish patch.

Changes:
- reduced empty upper screen through closer/lower camera and smaller FOV
- denser fantasy temple environment with arches, banners, steps, pillars, torches
- stone-road readability pass with seams, cracks, curbs, and rune markers
- modern/cyber-looking obstacles replaced with temple-themed procedural obstacles
- coins/powerups made brighter and easier to read
- smaller HUD/buttons and slightly fairer hitboxes

Slide animation remains parked; this patch does not retarget slide bones.
